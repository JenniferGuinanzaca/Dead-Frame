# Dead Frame
A Responsive Horror Cinema Archive
Dead Frame is a responsive horror cinema archive created for CSC 436 — Project 1: Static Foundations.

The site is designed as a small digital archive for exploring a small collection of horror films. The project focuses on creating a cinematic visual experience while demonstrating semantic HTML, modern CSS layout, responsive design, and vanilla JavaScript interactivity.

I originally planned to use a movie API to dynamically retrieve the films for the archive. However, I became nervous about relying on an external service during grading. Even if the API was working during development there was a slight chance the API would experience an outage or another issue causing it to stop working when the project was being evaluated. This resulted in me manually inserting 13 films instead.(capped it at 13 because it was a tier I project!! next time i'd just use an api)

## Running Locally
To run Dead Frame locally,
clone or download the repo and open a terminal in the project folder
run a static server from the root folder using:
`python3 -m http.server 8000`
then open http://localhost:8000 in your web browser.
